# fruit-and-vegetable-predicition
### Fruit and Vegetable Classification using Machine Learning

This project focuses on classifying fruits and vegetables using Machine Learning techniques. It uses the Fruits-360 dataset to train and test models for identifying six categories: Apple, Banana, Orange, Mango, Cabbage, and Potato.

The project implements **Support Vector Machine (SVM), Decision Tree, and Soft Voting Classifier** to classify images and compare model performance.

**Technologies Used:**
- Python
- NumPy
- Matplotlib
- Pillow (PIL)
- Scikit-learn
- Jupyter Notebook

**Key Features:**
- Image preprocessing and resizing
- Data normalization
- Training and testing datasets
- SVM and Decision Tree classification
- Ensemble learning using Voting Classifier
- Model evaluation using accuracy score and confusion matrix
- Fruit and vegetable image prediction

**Objective:** To explore image classification using traditional Machine Learning algorithms and compare their performance.
